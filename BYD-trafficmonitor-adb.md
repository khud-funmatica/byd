# BYD: отключение Traffic Monitor через ADB

На части прошивок приложение **Traffic Monitor** (`com.byd.trafficmonitor`) мешает нормальной работе мобильного интернета с SIM. Его можно отключить для текущего пользователя (user 0) через ADB.

## Требования

- Включена отладка по USB или по сети (`adb devices` показывает устройство).
- Команды выполнять с ПК: `adb shell …` или зайти в `adb shell` и выполнять без префикса.

## Отключить

```bash
adb shell pm disable-user --user 0 com.byd.trafficmonitor
```

При успехе обычно выводится `Package com.byd.trafficmonitor new state: disabled-user`.

## Проверить, что отключено

```bash
adb shell pm list packages -d | grep com.byd.trafficmonitor
```

- Если строка **`package:com.byd.trafficmonitor`** есть — пакет в списке отключённых (`-d`), отключение сработало.
- Если `grep` ничего не выводит — пакет не числится среди отключённых (либо не отключали, либо включили снова).

Дополнительно можно посмотреть состояние:

```bash
adb shell pm list packages -d
```

## Включить обратно (если понадобится)

```bash
adb shell pm enable com.byd.trafficmonitor
```

## После отключения

Перезагрузка машины не всегда обязательна, но если мобильный интернет не поднялся сразу — перезапустите головное устройство или отключите/включите режим полёта в настройках сети (если доступно).
